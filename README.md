# 🏡 Airbnb Price Analysis – Seattle  
**Tableau Data Visualization Project**

This project analyzes the **Seattle Airbnb Open Data** using a Tableau dashboard to explore pricing patterns across zipcodes, bedroom counts, and yearly trends. This is **my first Tableau project**, created during my August holiday when I started learning Tableau and data visualization.

## 🎯 Project Objectives
- Understand how Airbnb listing prices vary across Seattle.
- Practice building interactive dashboards as a beginner.
- Explore data cleaning, visualization, and storytelling.
- Present insights in a clear and structured way.

---

## ❓ Key Questions Explored
1. **Which zipcodes have the highest and lowest Airbnb prices?**  
2. **How does the number of bedrooms affect pricing?**  
3. **What is the distribution of bedroom counts in the dataset?**  
4. **How do prices and revenue change throughout the year?**  
5. **How does pricing vary geographically across Seattle?**

---

## 🔍 Key Insights
- Certain zipcodes stand out with significantly higher average prices.  
- More bedrooms generally correlate with higher listing prices.  
- Revenue trends show seasonal fluctuations across the year.  
- Mapping reveals clear geographic price variations between neighborhoods.
